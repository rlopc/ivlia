# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting: [open a private report](https://github.com/rlopc/ivlia/security/advisories/new), or open the repository's Security tab and choose "Report a vulnerability". Do not report them in public issues, pull requests or discussions.

Include what is affected (version or commit), how to reproduce it and its impact, if you know it.

## What to expect

ivlia is maintained by one person, on a best-effort basis:

- The report is acknowledged within 14 days.
- A confirmed vulnerability is fixed in a new release, and disclosed through a GitHub security advisory once the fix is out. The reporter is credited, unless they prefer not to be.

## Supported versions

Only the latest release gets security fixes.
